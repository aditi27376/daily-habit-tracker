# 🌱 Daily Habit Tracker

A simple and responsive web application for creating, managing, and tracking daily habits.

Built using **HTML, CSS, and JavaScript**.

## 🚀 Live Demo

https://aditi27376.github.io/daily-habit-tracker/

## 📌 Features

- ➕ Add new habits
- ✏️ Edit habits
- 🗑️ Delete habits
- ✅ Mark habits as completed
- 🔴 High, 🟡 Medium, and 🟢 Low priority
- 📚 Habit categories
- 🔍 Search habits
- 🔽 Filter completed and pending habits
- 📊 Track daily progress
- 🔥 Track habit streaks
- 📈 Weekly progress overview
- 🌙 Dark mode
- 💾 Data persistence using Local Storage
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
